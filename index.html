What's inside

Agents with cards

System prompt, model, connection, toolset per agent. Chats are self-sufficient: model and connection materialize at birth.

A real agentic loop

Think, call a tool, see the result, continue. Files, shell with danger analysis, approvals with session grants, MCP + custom JSON tools.

Councils

2-10 agents in one chat: per-member models, rounds, a shared table file. They genuinely argue.

Memory that works

Per-chat memory, digests pinned after the system prompt, compaction with snapshots. Long chats stay sharp.

Time machine

Roll back any message, files roll back with it (git snapshots). Full per-chat git mode: init, diff, commit, push.

Studio

Builds websites with a sandboxed live preview (CSP), real device frames (iPhone/Pixel/Galaxy/iPad) with UA/touch emulation, Figma-style activity feed.

Painter

Image chats with a canvas split and a variant strip. Drag a rect, vision describes the region into your prompt. Point editing for pixels.

Jobs and schedules

Background shell tasks with owners, watchers and branch inheritance. Cron schedules. Honest failure cards with one-tap fix.

Bridges

Telegram, Discord, Slack - your agents answer where you actually chat.

The story

Agora is built by one person in pair with an AI. The app is the workflow it implements: a human and agents sharing a workspace, files, memory and responsibility. Every feature shipped the same way: a real report from real use, implementation, 983-test regression, deploy to the live machine. No pitch deck: the commit history is the resume.

Source code is private (it's a product). Available on request - happy to grant repo access on a conversation.
